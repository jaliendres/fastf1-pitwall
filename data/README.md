# Dataset provenance

The included demo files were exported with FastF1 from the frozen HTTP
responses used by the official FastF1 documentation build:

- Source repository: <https://github.com/theOehrly/fastf1-doc-data>
- Snapshot commit: `a6412b80977c01e82d8f8e77adb074e6432c9fe5`
- Sessions: 2021 Spanish Grand Prix Qualifying and 2023 Azerbaijan Grand Prix Race
- Exported on: 2026-10-25

Only compact derived values needed by the dashboard are committed. Raw source
responses and credentials are not included.

FastF1's source code is MIT licensed. Formula 1 data and related marks remain
subject to their respective owners' terms and rights.
